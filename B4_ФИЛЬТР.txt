B4 — фильтр подбора ингредиентов
================================
Чтобы при выборе ингредиента в карточке блюда и заготовки не всплывали
химия (накладные), столы/мебель (основные средства) и товары-упаковка.
Показываются только товары типа «Ингредиент» и товары без категории.
Расчёт себестоимости НЕ меняется.

Распаковать ИЗ КОРНЯ проекта (где manage.py):

    tar xzf ~/Downloads/fc_b4.tgz -C .

Положит:
  • apply_b4_picker.py                              — патч (в корень)
  • foodcost/tests/test_ingredient_picker.py        — тест

Применить и проверить:

    python apply_b4_picker.py
    python manage.py test foodcost.tests.test_ingredient_picker
    python manage.py runserver

Патч идемпотентный — можно запускать повторно без вреда.
