ФАЗА 2 (ЗАКАЗЫ/КАССА, аналитика): order_analytics — по филиалам
================================================================
«Филиал» = Order.location. Требует Фазу 1 (branch_scope.py). Можно применять
независимо от патча ядра заказов (импорт и helper'ы скрипт обеспечивает сам;
если ядро уже применено — просто допишет недостающее).

Из корня проекта, командой tar:

    tar xzf ~/Downloads/fc_branch_p2_analytics.tgz -C .
    python apply_branch_phase2_analytics.py
    python manage.py test foodcost.tests.test_branch_analytics

Что сужается до филиалов пользователя (всё — из заказов/справочников):
  • orders_qs (снимок периода) → выручка/касса/банк/средний чек/ТОП блюд/
    методы оплаты/источники/доставка считаются из него;
  • сводка по филиалам — только твои филиалы;
  • графики по часам и по дням;
  • «повторные» клиенты — в разрезе филиала;
  • списания (WriteOff) — по location. ЗАОДНО чинит баг из кода: раньше
    списания подставлялись на каждый филиал общей суммой по стране;
  • расходы (FinancialExpense: аренда/зарплаты/маркетинг) — по location
    ТОЛЬКО если у модели есть поле location; иначе остаются как есть
    (без привязки к филиалу их нельзя разнести — поведение сохранено).

Супер-админ / без филиалов видят всё. Миграций нет.

Если у FinancialExpense ЕСТЬ поле филиала под другим именем (не location) —
скажи, подставлю его.
