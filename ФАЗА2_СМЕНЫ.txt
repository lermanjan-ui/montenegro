ФАЗА 2 (СМЕНЫ): ограничение по филиалам
========================================
Требует Фазу 1 (foodcost/branch_scope.py должен существовать).

Распаковать ИЗ КОРНЯ проекта (где manage.py):

    tar xzf ~/Downloads/fc_branch_p2_shifts.tgz -C .

Положит:
  • apply_branch_phase2_shifts.py                 — патч (в корень)
  • foodcost/tests/test_branch_shifts.py          — тест изоляции

Применить:

    python apply_branch_phase2_shifts.py
    python manage.py test foodcost.tests.test_branch_shifts
    python manage.py runserver

Что меняется:
  • Журнал смен (/shifts/): список смен и выпадашки «филиал»/«сотрудник»
    сужаются до филиалов пользователя.
  • Передача смены (/shift-handover/ и админ-вид): список передач ограничен
    филиалами пользователя.
  • Старт смены у повара (личный кабинет) уже самоограничен — не трогаем.

Супер-админ и пользователи без назначенных филиалов видят всё (как раньше).
Миграций нет (поле location уже есть в моделях). Патч идемпотентный.
Фильтрация только на чтение — создание записей не затронуто.
