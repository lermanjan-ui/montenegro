ФАЗА 2 (СПИСАНИЯ): ограничение по филиалам
===========================================
Требует Фазу 1 (foodcost/branch_scope.py).

Из корня проекта (где manage.py), командой tar — не кликом:

    tar xzf ~/Downloads/fc_branch_p2_writeoffs.tgz -C .
    python apply_branch_phase2_writeoffs.py
    python manage.py test foodcost.tests.test_branch_writeoffs

Что меняется:
  • /writeoffs/           — список списаний и выпадашка складов сужены до
    филиалов пользователя;
  • /writeoffs/analytics/ — аналитика считается только по филиалам
    пользователя (все суммы/разбивки наследуют фильтр).
Создание не трогаем: повару склад и так ставится из профиля.
Супер-админ / без филиалов видят всё. Миграций нет. Только чтение.
