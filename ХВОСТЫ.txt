ФАЗА 2 — хвосты: суммы по клиенту по филиалу + селект «Откуда» в перемещениях
=============================================================================
Требует уже применённую Фазу 2 (order_views.py / views_transfers.py пропатчены,
helper'ы scope_* есть в branch_scope.py).

Из корня проекта, командой tar:

    tar xzf ~/Downloads/fc_branch_p2_tails.tgz -C .
    python apply_branch_phase2_tails.py
    python manage.py test foodcost.tests.test_branch_tails

Что меняется (миграций нет, только чтение/шаблон):
  (а) customer_list — суммы в строках клиентов (кол-во заказов, потрачено,
      последний заказ, сайт/tilda, обеды) считаются ТОЛЬКО по заказам филиалов
      пользователя. Супер-админ / без филиалов — по всем (поведение как было).
  (б) перемещения — в карточке селект «Откуда» сужен до филиалов пользователя
      (новый контекст from_warehouses), «Куда» остаётся полным (хаб-правило).
      Серверный запрет чужого склада-источника и так был — это довод до UI.

Трогаются 3 файла:
  • foodcost/order_views.py                       (аннотации customer_list)
  • foodcost/views_transfers.py                   (контекст from_warehouses)
  • foodcost/templates/foodcost/transfer_detail.html  (селект «Откуда»)

Если путь к шаблону в проекте иной — скрипт честно скажет «не найден шаблон»,
тогда пришли фактический путь к transfer_detail.html.
